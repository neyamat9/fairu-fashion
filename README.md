# Fairu Fashion

An elegant, high-performance E-Commerce platform for women's dresses, traditional ethnic wear, and modern fashion collections.

## Architecture

- **`frontend/`**: Next.js 16 (App Router), React 19, Tailwind CSS v4 customer storefront.
- **`dashboard/`**: React, Vite, Tailwind CSS admin dashboard.
- **`server/`**: NestJS, Prisma ORM, PostgreSQL backend API.

## Features

- **Storefront**: Modern luxury aesthetic, fast shopping, filter & search, cart & checkout, customer account & order tracking.
- **Dashboard**: Full product, category, orders, customers, and site settings management.
- **Backend API**: Secure REST API with JWT authentication, caching, email notifications, and PostgreSQL database.
